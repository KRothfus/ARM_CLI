## Project

This is a project for the final course of Boot.Dev typescript course. I was tired of the manual intervention at multiple points throughout the 
dvd/blueray ripping process. I had to open makemkv, check the types of files that were on the disc, select the approprate ones, save the files to an external harddrive, then use handbrake to compress the movies/shows, and finally point handbrake to the location on the nas that they need to be saved to. This CLI project is intended to do as much of those steps upfront as to not have to baby sit the process.
